- narrow-band DG level-set method: level set primarily defined on the cells intersected by the interface
- extension of the level set to the face neighbors of the cut cells (all face neighbors or only the downstream ones): global face-based ghost-penalty extension or closest-point extension
- alternatively: advected band of the cut cells and one or several layers of vertex neighbors (`number of layers`; one layer reduces the band size, but should only be used with `signed_distance` and the thin feature removal; a warning is printed, if the interface reaches the outer boundary of the band within a time step) with geometric redistancing of the layers (first-order Taylor expansion from the closest point or, with `extension/redistancing = signed_distance`, the signed distance to the closest point with the tracked sign of each cell, which only changes if the interface passes through the cell, such that the redistancing never creates an interface, or, with `scaled_signed_distance`, this signed distance scaled with the gradient magnitude at the closest point); the layers are redistanced after each reinitialization or, with `extension/layer redistancing = every_time_step`, in every time step; optionally (`extension/cut clipped cells`), cells whose corner or face is clipped by the interface of an adjacent cut cell are redistanced by the Taylor expansion, such that they become cut cells (if the interface is still too small to be detected, they are excluded from the redistancing of the layers in this time step)
- optional removal of thin features, which cannot be resolved by the mesh (`thin feature removal/thickness`, DG advection of the band): after the advection, a cell is cleared from a phase, which is thinner than the threshold in the cell and either enclosed by two facing boundaries (branches of the interface or faces, at which the neighbor has the other sign) or not continued in any face neighbor; thin filaments disappear cell by cell from the tip instead of creating spurious interfaces; a cell is not cleared, if a face neighbor would have the other sign in the whole cell afterwards (the interface would lie on the shared face, where no cut cell represents it)
- alternatively: semi-Lagrangian band, where the level set is only stored on the cut cells and evaluated on the cut cells and their vertex neighbors by back-tracing the characteristics (no extension)
- sub-cycling of the semi-Lagrangian band for small time steps (`level set update cfl`): the level set is evaluated from a reference level set, which is only updated (with the reinitialization and the insertion of interface points), once the displacement since the reference exceeds a fraction of the cell size; the foot points at the reference time are computed by the backward integration over all time steps since the reference or by the characteristic map (`level set update characteristics`), which stores the displacement since the reference as a continuous field and only needs the velocity of the current time step
- explicit upwind DG advection (non-conservative form) on the narrow band with a prescribed velocity, optionally with a bound-preserving limiter (local maximum principle or sign preservation) or an artificial viscosity in the cells flagged by a modal smoothness indicator
- elliptic reinitialization on the cut cells (every n-th time step (`reinitialization frequency`), if the eikonal error exceeds a threshold or once the interface has travelled a given distance since the last reinitialization (`reinitialization displacement`, estimated by the sum of max |u| dt); SIPG coupling across all faces between cut cells or only across the faces crossed by the interface), with the interface penalty term on the zero level set of the advected level set or at advected interface points (front tracking with seeding in gaps (optionally conservative, `conservative insertion`: the weights of each cell with new points are scaled such that their sum is conserved, so that the total weight approximates the interface measure), merging of points and merge and break-up rules for topology changes, which remove the points of colliding parts of the interface (merging, pinch-off); removes the shrinkage of convex interfaces by the linear interpolation of the semi-Lagrangian band for p = 1; optionally, the cut cells around unresolved points, e.g., thin filaments, are redistanced at the subcell scale from the points and projected onto the cell polynomials (or, in the continuous level set space, interpolated at the nodes, `subcell transfer`), which either replaces the reinitialized level set or is prescribed in the reinitialization of the other cut cells)
- optional continuous level set on the cut cells (constrained L2-projection of the DG level set with an interface penalty) with normal vector and curvature for the output and as input for surface tension
- restart (subsection `restart`): with `save` >= 0, the state of the simulation (mesh, cut cells, level set on the cut cells and on the band, signs of the cells, reference of the sub-cycling, advected interface points, time and output records) is written every `write time step size` (wall-clock seconds or simulation time, `time type`), after the last time step and, if the `max wall time` is exceeded, before the simulation stops; `load` = i continues from the state i (0: latest, older states are kept up to `save` - 1) and reproduces the uninterrupted simulation for the same number of processes
- cases: `rotating_circle`, `vortex_bubble` (single vortex in 2D, deformation field of LeVeque in 3D), `zalesak_disk` (rigid-body rotation of Zalesak's slotted disk), `static_circle` (reinitialization of a scaled signed distance function of a circle/sphere at rest for convergence studies) `merging_circles` (two circles/spheres, which move towards each other with u = -U sign(x - m_x) e_x and merge; exact solution: union of the two translated disks/balls, with the gap, the neck, the area and the length of the interface), `breakup_circles` (two overlapping circles, which are squeezed towards their axis with u = -U sign(y - m_y) e_y, such that the neck pinches off at t = sqrt(r^2 - D^2/4) / U; exact solution: {|y - m_y| + U t < h_0(x)} with the half-height h_0 of the initial union, two lenses after the pinch-off, with the gap, the neck, the area and the length of the interface; 2D) and `static_particles` (particles from a particle list at rest, e.g., for the reinitialization of close interfaces; optionally with a cell-wise initial level set, which is the signed distance of the particle intersecting each cut cell)
